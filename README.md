# Desarrollo de Aplicaciones en Lenguaje Python

Repositorio dedicado al aprendizaje y desarrollo de aplicaciones con Python, correspondiente al curso de especialización en desarrollo de aplicaciones en lenguaje Python.

## 📚 Contenido

En este repositorio se organizan ejercicios, prácticas y proyectos realizados durante el aprendizaje de Python.

- **POO 2026-2027:** programación orientada a objetos y contenidos relacionados.
- **Ejemplo web:** prácticas de desarrollo web.
- **Laboratorio:** ejercicios y experimentos con Python.
- **Taskflow:** proyecto de gestión de tareas.
  
## 🛠️ Tecnologías

- Python
- Git
- GitHub

## 🎯 Objetivos

- Desarrollar habilidades de programación con Python.
- Aprender a diseñar aplicaciones utilizando buenas prácticas.
- Comprender la programación orientada a objetos.
- Practicar el control de versiones con Git y GitHub.
- Crear proyectos prácticos para consolidar los conocimientos adquiridos.

## 📁 Estructura del repositorio

La estructura se irá ampliando a medida que avance el curso.
